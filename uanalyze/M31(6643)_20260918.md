## 1. 近況發展

# M31 最新發展全解析：先進製程開案量創高與 CSP 自研晶片強勁拉動

2026 年營運加速推進，[[台積電 3nm 與 2nm 先進製程 IP 授權合約金額創下歷史新高]]，全球四大 CSP 雲端巨頭自研 ASIC 晶片需求強勁，帶動高速介面 IP 開案大量湧現，但需留意<<研研團隊全球擴充帶來的短期營業費用負擔與淨利受壓壓力>>。（資料日期：2026-08-15 來自非公開資料）

---

### **營收與獲利結構：從 2024～2025 費用投資期到 2026～2027 獲利收割期**

- **2025 年營運表現與體質**：  
  M31 2025 年合併營收年增 22.4％，創歷史新高，毛利率維持 100％，營業利益年增 18.5％。<<主因係預先於台灣、印度與北美擴充全球高階 IP 研發團隊，研發費用率短期攀升>>。（資料日期：2026-03-10、2026-04-15 來自非公開資料）  
- **授權金與權利金雙軌結構**：  
  目前授權金（License）占整體營收約 80%，為短中期營收成長主要拉動力；量產權利金（Royalty）占約 20%。隨 5nm/3nm 客戶晶片於 2026～2027 年進入大規模投片量產，[[高毛利權利金將成為第二道獲利爆發曲線]]。（資料日期：2026-07-20 來自非公開資料）

<a id="2"></a>
## 2. 產業趨勢

### **半導體架構革新：Chiplet 小晶片與 CSP 自研晶片浪潮**
1. **Chiplet 拆分架構**：晶片微縮面臨物理極限，Chiplet 拼接成為主流。M31 的 PCIe 5.0/6.0 與 UCIe 介面 IP 為小晶片溝通的必備通道。
2. **CSP 巨頭去通用 GPU 化**：Google (TPU)、Amazon (Trainium)、Meta (MTIA) 與 Microsoft (Maia) 加速開案，[[提供純 IP 廠龐大的客製化開案合約商機]]。（資料日期：2026-08-15 來自非公開資料）

---

<a id="3"></a>
## 3. 產品線分析

- **高速介面 IP (Interface IP)**：營收占比約 68%，涵蓋 PCIe 5.0/6.0、USB 4.0/3.2、ONFI 5.1、CXL 2.0/3.0，為主要成長引擎。
- **基礎 IP (Foundation IP)**：營收占比約 26%，涵蓋 Memory Compilers、Standard Cell Library，與台積電 OIP 聯盟深度綁定。
- **車用與工控 IP**：營收占比約 6%，通過 ISO 26262 ASIL-B/D 安全認證，提供長線高價值利基。（資料日期：2026-07-20 來自非公開資料）

---

<a id="4"></a>
## 4. 長短期展望

- **短期展望（2026 年）**：先進製程（3nm/2nm）授權金大幅入帳，全年開案金額保持 20%～25% 強勁年增。
- **中長期展望（2027～2028 年）**：客戶晶片量產規模化，高毛利權利金營收占比拉升至 30% 以上，營益率衝上 40%+。（資料日期：2026-08-15 來自非公開資料）

<a id="5"></a>
## 5. 供需分析

- **晶圓代工合作平台**：台積電（TSMC）、三星（Samsung）、英特爾（Intel IFS）、格羅方德（GF）、聯電（UMC）。
- **先進製程產能緊張**：台積電 3nm 產能滿載，M31 為少數能在 3nm/2nm 提供完整 PDK 驗證介面 IP 的獨家夥伴。（資料日期：2026-09-05 來自非公開資料）
