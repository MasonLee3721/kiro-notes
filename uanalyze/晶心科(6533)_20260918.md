## 1. 核心重點摘要 (小白懶人包)

- **全球 RISC-V 大腦藍圖龍頭**：晶心科是全球 RISC-V 架構 CPU IP 的前三大領導廠商，專門提供「晶片的大腦架構」。
- **開源 RISC-V 潮流浪潮**：因為 ARM 架構授權費用高昂且規則受限，全球晶片大廠（Meta, Google, 英特爾及微軟）紛紛轉向開源、免費可彈性客製的 RISC-V 架構，晶心科受惠最大！
- **AI 向量擴充與車用安全晶片**：
  1. **AI 向量擴充 (Vector)**：支援 AI 加速運算，獲多家 AI 晶片業者採用。
  2. **車用 ISO 26262 認證**：車用晶片認證嚴格，晶心科車用 CPU IP 已打入美系與台系車用供應鏈。

## 2. 營運發展與產品線分析

### 2.1 RISC-V CPU 大腦架構
- 晶心科 AndesCore 系列產品廣泛應用於 5G 基地台、物聯網（IoT）、車用電子與 AI 加速晶片。
- 毛利率高達 **99%～100%**，隨客戶晶片從設計端開案（領取授權金），進展到工廠量產（按顆收取權利金），權利金將帶來巨大的獲利彈性。

### 2.2 高階 AI 與車用安全布局
- RISC-V Vector（向量運算擴充指令集）成為 AI 邊緣運算的關鍵，開案占比顯著拉升。
- 車用晶片認證期長但生命週期遠比消費電子更長，能提供長期穩定的權利金流。

---

## 3. 籌碼與前置過濾觀察

1. **籌碼面**：主力與法人針對 RISC-V 長期去 ARM 化趨勢逢低鎖碼，籌碼相對穩定。
2. **前置過濾評價**：轉機與長線成長型 IP 標的，隨客戶晶片陸續量產，長期營運槓桿極高。
