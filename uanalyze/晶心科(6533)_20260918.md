## 1. 近況發展

# 晶心科最新發展全解析：去 ARM 化浪潮、RISC-V 生態加速與 AI 向量晶片大爆發

2026 年營運顯著強彈，[[全球科技巨頭與 RISE 聯盟加速轉向開源 RISC-V 架構]]，帶動公司高階 CPU 授權合約與 AI Vector 向量處理器開案暴增，但需關注<<開源軟體編譯器開發與工程團隊費用對短期利潤率的壓制>>。（資料日期：2026-08-20 來自非公開資料）

---

### **營收與獲利結構：從 2024～2025 費用投資期到 2026～2027 權利金爆發期**

- **2025 年營運表現**：合併營收年增 28.5%，毛利率保持 99.8%，營業利益隨開案結算急劇轉盈。（資料日期：2026-03-15 來自非公開資料）
- **出貨量累積**：累計採用晶心科 AndesCore IP 的晶片出貨量已打破 [[120 億顆大關]]。（資料日期：2026-09-12 來自非公開資料）

## 2. 產業趨勢

1. **全球去 ARM 化浪潮**：ARM 授權費用攀升，促使 Meta, Google, Intel, Nvidia 等巨頭成立 RISE 聯盟推動 RISC-V。
2. **美中晶片自主化**：亞系廠商加速全面導入 RISC-V 大腦架構。（資料日期：2026-08-20 來自非公開資料）

<a id="3"></a>
## 3. 產品線分析

- **RISC-V 高階 CPU 核心**：占營收約 65%，覆蓋 32/64 位元嵌入式控制。
- **AI 向量擴充 (Vector IP)**：占營收約 25%，專為 AI/ML 矩陣運算擴充。
- **車用 ISO 26262 核心**：占營收約 10%，通過 ASIL-D 最高功能安全認證。（資料日期：2026-09-12 來自非公開資料）

## 4. 長短期展望

- **短期展望（2026）**：AI 向量處理器與車用 IP 授權金大幅入帳，EPS 上看 11～13 元。
- **中長期展望（2027+）**：120 億顆晶片邁入投片量產高峰，高毛利權利金大幅注入。（資料日期：2026-09-12 來自非公開資料）
